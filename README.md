# გამოცდის ინსტრუქცია

1. სწავლის შედეგისთვის დასადასრურებლად გამოიყენეთ შეაბამისი საქაღალდე. თითოეულ საქაღალდეს აქვს `index.html` და `script.js` ფაილი, საჭიროების შემთხვევაში შექმენით `style.css`.

2. გამოცდის დასრულების შემდეგ შეინახეთ საბოლოო ვერსია გითზე, (`Git add .` , `git commit -m "დასრულებული გამოცდა"` , `git push`)

## სწავლის შედეგი 1

1.  გამოაცხადეთ ფუნქცია `getSum` და ასევე ორი ცვლადი: `number1`, `number2`
2.  მიანიჭეთ ამ ცვლადებს რიცხვითი მნიშვნელობები;
3.  არითმეტიკული ოპერატორების გამოყენებით შეკრიბეთ ცვლადების მნიშვნელობები;
4.  გამოტანის ოპერატორების მეშვეობით მიღებული შედეგი (ჯამი) დაბეჭდეთ შედეგი კონსოლში.

## სწავლის შედეგი 2: If/Else, ციკლები, ღილაკები და Input

1. შექმენით ორი ცვლადი: `age1` და შეინახეთ მასში რიცხვითი მნიშვნელობა. პირობითი ოპერაორის მეშვებით შეამოწმეთ, თუ ასაკი მეტია ან ტოლი 18 ის დაბეჭდეთ 'სრულწლოვანია', წინააღმდეგ შემთხვევაში დაბეჭდეთ 'არ არის სრულწლოვანი'.
2. სასურველი ციკლის გამოყენებით კონსოლში გამოიტანეთ ყველა ლუწი რიცხვი 1 დან 30 მდე.
3. HTML-ში შექმენით ღილაკი. როდესაც დააჭერთ ღილაკს, ღილაკის ქვევით გამოვიდეს შეტყობინება 'დამალული ტექსტი'.
4. HTML-ში შექმენით input ველი. როდესაც მასში ტექსტს აკრეფთ, მის ქვევით გამოვიდეს აკრიფეთი ტექსტი.

## სწავლის შედეგი 3: მასივები (Arrays)

1. გაქვთ შემდეგი სახელები:  
   `ana`, `nika`, `elene`, `diana`, `avtandili`, `nini`, `levani`, `nugzari`, `qetevani`, `zura`, `teona`.

   გამოიყენეთ `for` ციკლი და შექმენით ახალი მასივი, სადაც იქნება მხოლოდ ის სახელები, რომელთა სიგრძე 5 ასოზე მეტია.

2. დაამატეთ ერთი სახელი ახალი მასივის დასაწყისში და ერთი სახელი ბოლოში.

3. მოცემულია შემდეგი მასივი:

```javascript
arrOfAges = [15, 12, 25, 18, 20, 19, 34, 45, 17];
```

`filter()` მეთოდის გამოყენებით შექმენით ახალი მასივი, სადაც იქნება მხოლოდ ის ასაკი, რომელიც მეტია 18-ზე .

4. მოცემულია ორი მასივი:

```javascript
arr1 = [-2, 0, 5, 9, 1];
arr2 = [6, 3, -4, 10, 7];
```

გააერთიანეთ ეს ორი მასივი და მიიღესთ ახალი მასივი, დაალაგეთ ახალი მასივი კლებადობით და შედეგი გამოიტანეთ კონსოლში.

## სწავლის შედეგი 4: Date, String, Storage, Time, alert, Event Listeners

1. დროისა და თარიღის ფუნქციის გამოყენებით, მიიღეთ დღევანდელი დღე და დაბეჭდეთ მიმდინარე რიცხვი, თვე და წელი კონსლში;

2. მოცემულია ცვლადი: name = `ilarion`. ჩაშენებული ფუნქციის დახმარებით გადაიყვანეთ სტრიქონი მაღალ რეგისტრში;

3. შექმენით ინფუთი და ღილაკი , ღილაკზე დაჭერისას შეინახეთ ლოკალურ საცავში ინფუთში ჩაწერილი ტექსტი. გვერდის გადატვირთვისას კონსოლში
   გამოიტანეთ ლოკალურ საცავში შენახული ტექსტი.

4. შექმენით ღილაკი , ღილაკზე დაჭერისას alert ის დახმარებით გამოაჩინეთ შეტყობინება "Hello JavaScript".

5. ტაიმეტის ფინქციის გამოყენებით კონსოლში ყოველ 1 წამში დაბეჭდეთ ცფრები 1 დან 10 ის ჩათვლით

## სწავლის შედეგი 5: HTML ელემენტების შეცვლა

1. გამოიყენეთ `getElementById()`, `querySelector()` ან `querySelectorAll()` HTML ელემენტების საპოვნელად. თითოეული ელემენტი გამოიტანეთ კონსოლში

2. შეცვალეთ ნაპოვნი ელემენტების ფერები და ზომები. შეგიძლიათ შეცვალოთ:
   - ტექსტის ფერი
   - ფონის ფერი
   - ფონტის ზომა
   - კლასის დამატება ან წაშლა

3. ჯავასკიპდიდან შექმენით ახალი პარაგრაფი ტექსტით და დაამატეთ ის HTML გვერდზე.

4. ნაპოვ ელემენტებზე დაამატეთ event listener-ები (`focus`, `blur`, `change`, `click`). როდესაც რომელიმე ივენთი ამოქმედდება, კონსოლში აჩვენეთ ივენთის შესაბამისი შეტყობინება.
